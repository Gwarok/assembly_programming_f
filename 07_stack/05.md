Program 5: Pushing and Popping 64-bit Values
Step-by-Step Stack Explanation
Step 1: Loading values
mov rax, 0x1122334455667788
mov rbx, 0x1234


Execution begins at _start.
- RAX receives 0x1122334455667788.
- RBX receives 0x1234.
Neither instruction affects the stack, so RSP remains unchanged.

Step 2: Pushing values onto the stack
push rax
push rbx


- push rax stores the 64-bit value in RAX on the stack. RSP decreases by 8 bytes.
- push rbx stores the value in RBX on the stack. RSP decreases by another 8 bytes.
The second value pushed, 0x1234, becomes the top of the stack.

Step 3: NOP instruction
nop


NOP performs no operation. It does not modify the stack or any register values.

Step 4: Popping values from the stack
pop rbx
pop rax


- pop rbx retrieves 0x1234 from the top of the stack and places it into RBX. RSP increases by 8 bytes.
- pop rax retrieves 0x1122334455667788 and places it into RAX. RSP increases by another 8 bytes.
Both values return to their original registers, and RSP returns to its initial position.

Step 5: Program termination
mov rax, 60
xor rdi, rdi
syscall


RAX is set to 60 to select the Linux exit system call. RDI is cleared to zero to indicate successful termination. The syscall ends the program.

No additional stack operations occur during termination.

Observations from Execution
When running the program using GDB, the following observations can be made:
1. Initially, RAX contains 0x1122334455667788 and RBX contains 0x1234.
2. Each PUSH instruction decreases RSP by 8 bytes.
3. After both PUSH instructions, the stack contains two 8-byte values, with 0x1234 at the top.
4. The first POP retrieves 0x1234 into RBX.
5. The second POP retrieves 0x1122334455667788 into RAX.
6. RSP returns to its original position after both values are popped.
7. Both registers recover their original values before the exit instructions execute.

Conclusion
This program demonstrates how the stack stores and retrieves 64-bit values using PUSH and POP. Each operation reserves or releases 8 bytes, regardless of the actual magnitude of the value being stored.

The values are retrieved in reverse order because the stack follows the Last In, First Out principle. After both POP instructions, RSP returns to its original position.

Key observation: Even though 0x1234 is a relatively small value, pushing RBX still occupies 8 bytes because the instruction operates on a 64-bit register. The stack allocation depends on the operand size, not the number of significant digits in the value.
